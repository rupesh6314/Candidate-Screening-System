# Security

Never commit production credentials or secrets. Use deployment secret managers. Student data should be treated as confidential.

Included controls: bcrypt password hashing, HTTP-only auth cookie, Helmet, CORS allow-list, rate limiting, schema validation, upload limits, RBAC, database constraints and audit logging.

Before production: HTTPS, managed secrets, backups, encryption, SSO/OIDC, data-retention policy, privacy/legal review, field masking, centralized monitoring and penetration/security review.
